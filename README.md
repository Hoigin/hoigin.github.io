# 📝Hoigin's Blog

> 一个简约、优雅且拥有极强 Markdown 渲染能力的博客构建系统。致力于提供从本地写作到线上发布「无缝衔接」的完美体验。

## 💡 初衷与理念 (Philosophy)

开源社区中从不缺乏制作精美的博客模板，也不乏如 Hugo、Hexo 等优秀的静态网站生成框架。然而，对于许多以 Markdown 作为首选写作格式的开发者来说，从「写出文章」到「完美发布」的过程却并不总是那么顺畅。

由于 Markdown 语法的标准（CommonMark, GFM 等）并不统一，我们在本地编辑器（如 Typora）中精心排版的文档，在渲染成 HTML 发布后，常常会遭遇格式错乱、公式无法解析或图表丢失等排版问题。本项目正是希望解决此问题，参考 Typora 强大的语法支持特性，在底层构建了极具灵活性的渲染引擎，并在前端保持了极致的克制。作者无需在发布前反复调整语法以适应博客框架，真正做到本地所写即线上所见，专注于写作本身。此外，极简的主页设计剔除了一切分散注意力的冗余元素，让内容以最简约、优雅的方式呈现，让读者专注于阅读。

## ✨ 核心特性 (Features)

为了实现极大的灵活性并兼容尽可能广的写作习惯，本项目对以下内容提供了开箱即用的深度渲染支持：

📦 **GitHub 标准 Markdown (GFM) 全面支持**
  
完美解析标准链接、章节链接 (Section Link)、自定义锚点 (Custom Anchor)、图像、列表与任务清单、Emoji 以及脚注 (Footnotes)。特别支持 GFM 标准的五种 Alerts（Note, Tip, Important, Warning, Caution）及其复杂的嵌套结构。
  
🧮 **硬核数学公式渲染 (MathJax)**

基于 MathJax 驱动，不仅支持常规的行内/块级数学公式，还深度兼容物理、化学等专业学科特有的 $\LaTeX$ 宏包语法支持。

💻 **超过 190 种语言的代码高亮 (highlight.js)**

集成强大的 highlight.js，无论是主流语言还是极小众的编程语言，都能获得精准、美观的代码块语法高亮显示。

📊 **强大的图表支持 (Mermaid)**

内置 Mermaid 客户端侧渲染支持。只需编写纯文本，即可在博客上动态生成流程图、时序图、状态图等复杂图表。

✍️ **Typora 专属扩展语法**

无缝衔接 Typora 用户的写作习惯，原生支持 `==高亮==` (Highlight)、`^上标^` (Superscript) 与 `~下标~` (Subscript) 等扩展语法。
